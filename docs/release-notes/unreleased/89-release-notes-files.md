# Release notes come from one file per PR

### What changed

- For the dev team: each PR now adds its release notes as its own file in `docs/release-notes/unreleased/`, and `pnpm release-notes` joins them into this page when Paul deploys, dated by when each PR merged. Open PRs no longer have to be updated every time another one merges.
- CI now asks for a notes file when a PR changes the game; a `no-release-notes` label skips that for changes testers can't see.
